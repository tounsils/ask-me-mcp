ask-me-mcp

A persona MCP server. Ask an assistant about the operator's work, patterns, availability, and offer — answers are grounded in public sources, not invented.

Endpoint

POST /api/mcp

Streamable HTTP transport, stateless per request. There is no browser UI here — this URL is meant to be added as a connector in an MCP client.

Connect it

  • Claude — add as a custom connector using the /api/mcp URL above.
  • ChatGPT — register the same URL through the Apps SDK.
  • Locally over stdio — npm run build then node dist/src/server.js.

Source

github.com/tounsils/ask-me-mcp — MIT licensed. A reference implementation of the MCP-Server Harness pattern.
